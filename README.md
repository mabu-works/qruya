## 📖 概要

ビルド不要で、生成はすべてお使いの端末のブラウザ内で完結し、入力内容が外部に送信されることはありません。

## ✨ 機能

- テキスト・URLを入力するテキストエリア（入力するとその場でプレビューが更新されます。「QRコードを作る」ボタンでも生成できます）
- 設定
  - 出力サイズ：256 / 512 / 1024 / 2048 px（正方形）
  - 前景色（模様の色）と背景色をカラーピッカーで選択
  - 誤り訂正レベル：L（約7%）／M（約15%）／Q（約25%）／H（約30%）
- プレビュー：Canvas に QRコードを表示（周囲に4モジュール分の余白＝クワイエットゾーン付き）
- PNGダウンロード：選択したサイズ・色で Canvas の内容を PNG として保存します（ファイル名 `qruya-qr.png`）
- プリセットボタン
  - 「URLの例を入れる」：`https://example.com/` を入力します
  - 「まぶ鯖の招待リンクを入れる」：まぶ鯖の招待リンク `https://discord.gg/GKkW4wCAVp` を入力します
  - 「クリア」：入力を空にします
- エラー表示（日本語）
  - 空入力のとき：「テキストを入力してください。」（完全に空のときは案内のみで、エラーは出しません）
  - 長すぎて収まらないとき：「入力が長すぎてQRコードに収まりません。文字を減らすか、誤り訂正レベルを下げてください。」
- 日本語などの文字はUTF-8で符号化します
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）
- テーマ切り替え（ダーク／ライト、手動トグル。選択は端末内に保存されます）

## 📝 使い方

1. テキストやURLを入力します（プリセットボタンで例やまぶ鯖の招待リンクを入れることもできます）。
2. 出力サイズ・色・誤り訂正レベルを選ぶと、プレビューがその場で更新されます。
3. 「PNGでダウンロード」を押すと、選択したサイズ・色の PNG 画像が保存されます。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。Web 版と同じ設定（出力サイズ・誤り訂正レベル・前景色／背景色、クワイエットゾーン4モジュール）で QR コードを生成し、PNG で保存できます。日本語などの文字は UTF-8（ECI）で符号化します。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Qruya.exe` を生成します（バイナリは Release に添付しません）
- QR コード生成には QRCoder 1.6.0 を使用しています

## 🧪 テスト

依存パッケージなしで Node の標準テストランナーを使います。

```
npm test
```

コアロジック（`js/qr-core.js`）の定数・入力分類・レイアウト計算と、同梱ライブラリによる実際の生成結果（モジュール数・暗モジュール数・ファインダパターン等）を検証します。

## 📋 技術メモ

- 素の HTML / CSS / JavaScript ＋ 同梱の qrcode-generator のみ。フォントはシステムの日本語フォントスタック。
- ロジックは DOM 非依存のコア（`js/qr-core.js`）と DOM 配線（`app.js`）に分離しています。
- QRコード生成ライブラリとして、Kazuhiko Arase 氏の **qrcode-generator 1.4.4** を `lib/qrcode.js` に同梱しています（cdnjs から取得した非圧縮版、56,694 バイト）。実行時に外部 CDN へはアクセスしません。
  - Copyright (c) 2009 Kazuhiko Arase、MIT License。ライセンス表記は `lib/qrcode.js` の先頭と `lib/LICENSE-qrcode-generator.txt` にあります。
  - 型番（バージョン）は 0（自動選択）で生成し、収まらない場合は例外を捕捉して日本語エラーで案内します。
  - 文字の符号化は同梱ライブラリの UTF-8 変換（`qrcode.stringToBytesFuncs['UTF-8']`）に切り替えて行います。
- 描画は生成したモジュール行列を使って Canvas に直接描いています（セルサイズは整数へ切り捨て、余りは中央寄せ）。ダウンロードも同じ Canvas から行うため、プレビューと保存画像が一致します。
- 入力内容はブラウザ内でのみ処理され、サーバーには何も送信されません。端末内に保存されるのはテーマ設定（`qruya-theme`）だけです。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: qruya-v1、qrcode-generator を含む）。
- QRコードは株式会社デンソーウェーブの登録商標です。
